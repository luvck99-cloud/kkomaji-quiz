# 꼬마 지식 탐험대 — 웹앱 배포 파일

## 포함 파일
- `index.html`: 퀴즈 앱 본체
- `manifest.webmanifest`: 홈 화면 설치 설정
- `sw.js`: 서비스 워커(기본 파일 캐시)
- `icon.svg`, `icon-192.png`, `icon-512.png`: 앱 아이콘

## 가장 쉬운 배포: GitHub Pages
1. https://github.com 에서 계정을 만들거나 로그인합니다.
2. 새 저장소(Repository)를 만듭니다. 이름 예: `kkomaji-quiz`
3. 이 ZIP을 풀고 파일 4개를 저장소 최상위(root)에 업로드합니다.
4. 저장소의 **Settings → Pages**로 갑니다.
5. **Build and deployment → Deploy from a branch**를 선택합니다.
6. Branch는 `main`, folder는 `/(root)`로 선택하고 **Save**를 누릅니다.
7. 잠시 기다린 뒤 Pages 화면에 표시된 주소를 엽니다. 보통 `https://사용자이름.github.io/kkomaji-quiz/` 형식입니다.

## 갤럭시에서 홈 화면에 추가
1. 휴대폰에서 위 배포 주소를 Chrome으로 엽니다.
2. 오른쪽 위 `⋮` 메뉴를 누릅니다.
3. **앱 설치**가 보이면 선택하고 설치합니다. 그렇지 않으면 **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 '지식 탐험대' 아이콘으로 실행합니다.

## 알아둘 점
- GitHub Pages 배포에는 GitHub 계정이 필요합니다. 이 ZIP 자체가 공개 URL을 자동 생성하지는 않습니다.
- 학습 기록은 해당 브라우저의 기기 내부 저장소에 보관됩니다. 브라우저 데이터 삭제나 다른 기기 사용 시 기록이 공유되지 않습니다.
- 인터넷 없이도 이전에 열린 기본 화면을 일부 사용할 수 있도록 캐시를 넣었지만, 첫 접속과 설치에는 인터넷이 필요합니다.
- 이 버전은 작동 가능한 시제품입니다. 레벨별 문항 수는 20개를 목표로 구성했지만, 모든 1,000문항을 전문가가 검수한 최종 콘텐츠라고 보장하지 않습니다. 실제 자녀 학습에 본격 사용하기 전 문항·정답을 검토해 주세요.
